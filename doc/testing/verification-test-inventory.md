Last updated: 2026-09-20

This is the repository copy of the team RVTM for the whole FieldDay repository. A status of **Partial** means the listed test has not completed every acceptance criterion; it does not mean its feature is absent. A requirement can be marked not run when its feature or test environment is not ready. Code described as implemented in an open PR becomes part of the release once that PR is merged through `dev` to `main`.

## CI plan

The session integration script deliberately creates and deletes records. It is not in CI yet because CI needs an isolated MongoDB test database and repository secret before it can safely connect. The target is 2026-09-27. The existing build workflow runs lint, backend validation, and Expo exports in a fresh GitHub-hosted Ubuntu runner.
